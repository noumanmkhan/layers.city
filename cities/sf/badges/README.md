# San Francisco neighborhood badges

One-colour drawings (viewBox 0 0 240 120; classes m ink, k knockout, ms/ks strokes), one per Analysis Neighborhood,
named by its slug. engine/badges.py sf places each inside its neighborhood. Public buildings and landscape only:
no logos, signage or anyone's artwork. Each drawing shows what is inside its own neighborhood (checked against the
polygons October 31, 2026): Mission Dolores is in Castro/Upper Market, the Painted Ladies' Alamo Square in Hayes
Valley, City Hall in the Tenderloin, the Dragon Gate in Financial District/South Beach (so Chinatown has Grant
Avenue's rooftops instead), the Golden Gate Bridge's south tower and Fort Point in the Presidio.
To add one: drop <slug>.svg here, run python3 engine/badges.py sf, then assemble.
