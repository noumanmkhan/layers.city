# App contract

- `DATA_CONTRACT.md` (this folder) describes the data the website publishes for the iOS app. The
  website owns it: update it here, in the same commit as the data change.
- The iOS app lives in its own repo, `noumanmkhan/layers.city.ios`. Its product brief
  (`APP_BRIEF.md`) and its Claude instructions (`CLAUDE.md`) live there only.
- That repo keeps a copy of `DATA_CONTRACT.md` at its root. When the contract here changes, copy it
  over (a separate commit in the app repo).
